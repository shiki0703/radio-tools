# 動画クリッパー v7 — Windows向け

動画を自動で文字起こししてテロップを焼き込み、盛り上がった場面の切り抜きを作ります。
すべてこのPCの中で処理し、動画を外部に送りません。元の動画は変更しません。

v7 は Radio Sync と同じ作りに揃えた版です(v6 から変わった点は下の「v6 からの変更」)。

## 準備(はじめに1回だけ)

1. Python 3.12 以降をインストールします(python.org。インストール画面で「Add python.exe to PATH」にチェック)。
2. FFmpeg をインストールします。PowerShell で `winget install Gyan.FFmpeg` を実行し、PCを再起動します。
3. `setup_windows.bat` をダブルクリックします。必要な部品を `.venv` に入れます(インターネット接続が必要・数分)。

初回の文字起こしでは、AIモデルを自動でダウンロードします(標準 約0.5GB、高精度 約1.6GB。それぞれ初回だけ)。

文字起こしの精度は「標準」と「高精度」から選べます。高精度は標準の1.5倍ほどの時間がかかりますが、
聞き取りにくい言葉の誤りが減るため、仕上げには高精度をおすすめします。

## 使い方

`start_windows.bat` をダブルクリックすると、Edge の専用ウィンドウで画面が開きます(黒い画面は出ません)。

1. **動画を選ぶ** — 「動画ファイルを選ぶ」でPC内の動画を選びます。制作ハブの「テロップ・切り抜きへ送る」で送った動画は自動で入ります。
2. **処理の設定** — 処理内容(文字起こし+テロップ/切り抜き)、テロップの見た目(元動画と切り抜きで別々。プレビューは動画の1コマの上に表示され、ドラッグで位置を調整)、切り抜きの向きと長さ、画質優先、文字起こしの精度。設定は次回も使われます。
3. **処理** — 進み具合・残り時間を表示し、中止できます。画面を閉じても処理は続きます。
4. **確認・修正** — テロップ付き動画を見ながら、行ごとに文字を直せます(時刻ボタンでその箇所を再生、Enterで次の行)。
   行を選ぶと、その行の**分割**(カーソル位置で2つに分ける・Ctrl+Enterでも可)、**下に追加**、**削除**、開始/終了の**0.1秒ずつの微調整**ができます。
   テロップが音声より早い・遅いときは「テロップ全体のタイミング」でまとめてずらせます。
   切り抜き候補のカードでは「この切り抜きのテロップ」を開くと、その切り抜きに入る行だけを見ながら直せます。
   「話題の見出し」を入にしていれば、左上に出す見出しもここで直せます。
   見た目も変えて「この内容で作り直す」で元動画・切り抜きを作り直せます。直した内容は自動保存されます。

処理結果は `results\日時\` に保存されます(captioned.mp4、subtitles.srt、titles.srt、clip_1〜5.mp4、highlights.json、project.json)。
「最近の処理」から開くと、後日でも確認・修正を続けられます。

画面を閉じて約3分たつと、裏で動くプログラムも自動で終了します(処理中は終了しません)。

## 困ったとき

- **画面が開かない** — 先に `setup_windows.bat` を実行したか確認し、もう一度 `start_windows.bat`。原因は `data\server.log` に記録されます。
- **「ffmpeg が見つかりません」** — 準備の手順2をやり直し、PCを再起動してください。
- **アプリケーション制御ポリシーでブロックされた** — Windows のセキュリティ機能が部品(DLL)を止めています。職場のPCでは管理者に確認してください。
- **修正したのに作り直せない** — 作業用の動画(results の中の _compressed.mp4、または元の動画)が移動・削除されていると作り直せません。

## v6 からの変更

- 画面を Radio Sync と同じデザイン・ステップ表示(動画を選ぶ → 処理の設定 → 処理 → 確認・修正)に変更
- ブラウザのタブではなく Edge の専用ウィンドウで開き、黒い画面を出さない(`pythonw`)。`start.bat` / `launcher.py` は `setup_windows.bat` / `start_windows.bat` に置き換え
- 動画はアップロードせず、PC内のファイルを直接使う
- このPC専用(127.0.0.1 と起動ごとの合言葉)。スマホ・タブレットからの利用は廃止
- Windows 専用(Mac 版の起動ファイル・マニュアル・フォント設定は削除)
- 「話題の見出しを左上に出す」を入にすると、いま何の話かを短い言葉で画面の左上に焼き込む(元動画・切り抜きの両方)。
  細かさは「話ごと(1〜4分)/コーナーごと(3〜6分)/動画に1つ」から選べる。
  見出しは字幕から自動で作り(例: 常識クイズ、ドーナツ、カレーライス)、確認・修正の画面で直せる
- 切り抜きは、会話を話題のまとまりに区切ってから選ぶ(話の途中で始まって途中で終わる切り抜きになりにくい)。
  長さは「1本の長さの目安」に対して0.7〜2倍の範囲で前後する
- 処理ごとに project.json を保存し、「最近の処理」から開き直してテロップ修正を続けられる
- 長すぎるテロップ(一続きの発話)は、単語の切れ目で読める長さに自動で分ける
- テロップの分割・追加・削除・時刻の微調整・全体のタイミングずらしを画面から行える
- Flask を使わず、Python 標準ライブラリのサーバー(`server.py`)に変更
- v6 の9ページのセットアップマニュアルは内容が古くなるため、v7 には含めていません

## 開発

- `server.py` … 画面用サーバー(ファイル選択・処理ジョブ・結果の保存と配信)
- `web/` … 画面(HTML/CSS/JavaScript、外部ライブラリなし)
- `src/` … 前処理・文字起こし・テロップ焼き込み・話題の見出し・盛り上がり検出・切り抜き
- `main.py` … コマンドで処理する場合(`.venv\Scripts\python.exe main.py input.mp4`)
- テスト: `.venv\Scripts\python.exe -m unittest discover tests`
- 他のツールから動画を渡す: `.venv\Scripts\pythonw.exe server.py --open "動画のパス"`

## スマホから使う(同じ Wi-Fi)

ふだんは、この PC からしか開けません。スマホを使うときだけ開きます。

1. PC の画面の右上「📱 スマホ」を押す
2. 出てきた **QR をスマホのカメラで読み取る**(それだけでつながります)
   - QR が読めないときは、表示されたアドレスを開いて **6桁の合言葉** を入れます(10分で切れます)
3. 使い終わったら「つながるのをやめる」を押す

できること:
- スマホの中の動画を「📤 動画を送る」で PC に送り、そのまま処理できます(保存先は `data/uploads/日付`)
- 処理の設定、処理の開始と進み具合、テロップの確認・修正まで、PC と同じことができます
- 画面が狭いときは、下のタブでステップを移動します

注意:
- 初回は Windows が「ネットワークアクセスを許可しますか」と聞くことがあります。**プライベートネットワーク**で許可してください
- 合言葉を知っていれば同じ Wi-Fi の誰でもつなげます。自宅や事務所など、信頼できる Wi-Fi で使ってください
