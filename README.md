# ラジオ制作ツール

ラジオ番組の収録素材から、本編の動画とSNS用の切り抜きを作るための道具一式です。
Windows PC 1台の中だけで動きます。動画や音声を外部に送ることはありません。

## 使いはじめる

1. このページの緑の **Code** ボタン → **Download ZIP** で一式をダウンロードします
2. ZIP を展開して、好きな場所（例: `ドキュメント`）に置きます
3. **はじめる.bat** をダブルクリックします

初回だけ、必要なもの（Python・FFmpeg・音声と文字を扱う部品）を自動で取ってきます。3分ほどで終わり、そのままブラウザで開きます。

- PC の設定（環境変数やインストール済みのソフト）は変えません。すべてこのフォルダの中に入ります
- 2回目からは数秒で起動します。デスクトップにできた「ラジオ制作ツール」からも開けます

## 更新

**はじめる.bat** を起動したときに、新しい版があれば知らせます。`Y` を押すだけで、ダウンロード・差し替え・再起動まで済みます。

作業中のデータ（`data` / `results` / 設定）は差し替えの対象外なので、更新しても今までの作業は残ります。途中で失敗したときは、元の状態に戻してから終わります。

## 入っているもの

| フォルダ | 役割 |
| --- | --- |
| `制作ハブ` | 2つのツールの入口。起動と、できた動画の受け渡しをする |
| `radio_sync` | ラジオ音声とカメラ映像を突き合わせて、本編の動画を作る |
| `video-clipper-v7` | 動画にテロップを入れ、盛り上がった所を切り抜く |
| `launcher` | 起動と更新のしくみ（`はじめる.bat` から呼ばれる） |
| `runtime` | 自動で作られる。Python と FFmpeg が入る（配布物には含まれない） |

## 動かすのに必要なもの

Windows 10 / 11 と、初回セットアップのときだけインターネット接続。
それ以外は自動で用意するので、事前に入れておくものはありません。

## 開発用

手元の3つのツールを、この配布のかたちに集めなおす:

```
python launcher/collect.py
```

`launcher/version.json` の `version` を上げて push すると、利用者の次回起動時に更新が案内されます。
