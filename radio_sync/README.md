# Radio Sync 0.3 — Windows向け試作版

その日のラジオ生音声と収録動画を複数選択し、カメラ音声との照合結果から話数別MP4を作ります。
**完成版ではありません。実収録はiPhone 1台・スタジオ収録の4話でのみ確認しています。**

ひと目でわかるガイド(できること・導入手順、A4 2ページ): `manual\Radio Sync ガイド.pdf`(再生成: `.venv\Scripts\python.exe tools\build_guide.py`)

## 起動

1. このZIPを任意のフォルダへ展開します。
2. Windows版Python(Tkinterとpyランチャーを含む。3.14で動作確認)をインストールします。
3. `setup_windows.bat` を実行します。初回の依存ライブラリ取得にインターネットが必要です。
4. FFmpeg(libx264対応版)を PATH に通すか、`ffmpeg.exe` と `ffprobe.exe` を本フォルダ内の `bin` に置きます。
5. `start_windows.bat` を実行すると、操作画面がMicrosoft Edgeのアプリウィンドウで開きます。

画面はPC内(127.0.0.1)だけで動くWebページです。起動ごとの合言葉が必要なため、他のPCやWebサイトからは操作できません。
画面を閉じて約3分たつと、裏で動くプログラムも自動で終了します(照合・書き出し中は終了しません)。

## 操作の流れ

1. **素材を選ぶ** — ラジオ音声(1ファイル=1話)とカメラ動画を追加。フォルダを選ぶと映像の有無で自動振り分けします。
2. **自動照合** — 所要時間の目安、進み具合、残り時間を表示。中止できます。
   8秒ごとの照合結果を「カメラの位置のずれが前後でそろっているか」でつなぎ、一致スコアが低くても(別マイク・反響など)同じカメラが続いていればカメラ映像を使います。
   カメラのファイルの始まり・終わりでは1/30秒単位で切り替え、ラジオ側の録音停止などでずれが変わる所は前後の波形から切り替え位置を探します。時計のずれ(ドリフト)は直線で補正します。
   カメラ映像を当てていても、カメラの音とほとんど一致しない区間(ラジオにしか入っていないジングル等)は「要確認」にします(一致を確認できた範囲の外で一致スコア0.1未満、範囲内で0.05未満)。
3. **確認・調整** — 「カット一覧」でカットごとに確認します。カットは同じ映像が続くひとまとまり(同じカメラの続き、または同じ静止画)です。
   - 絞り込み(すべて/要確認あり/静止画/カメラ)と、◀ ▶ で該当カットへ移動(他の話も含む)
   - 静止画のカットは「画像を選ぶ」で、既定の画像・追加した画像・カメラの場面から選べます(「この話の静止画すべてに使う」も可)。再生中に「📷 この場面を静止画候補に」でカメラの場面を画像として保存できます(iPhoneのHDR映像は色を補正して保存)
   - プレイヤーの下の波形(再生位置の前後±3/±10/±30秒): カメラの波形を左右にドラッグして、ラジオの山にそろえるとずれを調整できます。スライダー(±30コマ)でも同じです。カット一覧タブではカット全体、区間の細かい調整タブではその区間だけが動きます
   - タイムラインはドラッグで再生位置を動かせます。拡大タイムライン(前後10秒/1分/5分)のカットの境目のつまみをドラッグすると、カメラ映像の始まり・終わりを動かせます(カメラのファイルが録画していない所へは動きません)
   - 「抜き取り確認」: 各カットの冒頭・途中・終盤と切り替わりの前後だけを4秒ずつ続けて再生
   - カット全体のずれをまとめて±1/±10コマ調整(←→キーでも可)、カットごとの静止画化・OK、要確認のまとめてOK
   - 静止画にした区間も、参考としてカメラ映像を薄く表示
   - 「区間の細かい調整」タブで8秒単位の調整もできます:
     - ラジオ音声とカメラ映像をその場で同期再生(書き出し不要)。「カメラの音も重ねる」でずれを耳でも確認
     - ラジオとカメラの波形を上下に並べて表示し、山の位置で合わせる
     - コマ送り(±1/±10コマ、±1秒)、時刻の直接入力、「前の区間の続き」「次の区間とつなげる」
     - 「この付近を自動で探す」(現在位置の前後20秒を再照合)
     - 再生位置での区間分割・次の区間との結合(カメラのファイルの切れ目対策)
   - キーボード: Space 再生/停止、←→ 1コマ、Shift+←→ 10コマ、Enter OKして次へ、N/P 次/前の要確認、Ctrl+Z 元に戻す
4. **カット** — 1本の話を複数のファイルに分けたり(区切る)、いらない部分を取り除いたり(削る)できます。画面右上の「▶ 見る / ✂ 区切る / 🗑 削る」で切り替えます。
   ここでは、**区切り**=ファイルの境目(青い線)、**カット**=区切られた範囲(そのまま1つのファイルになる)、**削る範囲**=書き出さない所(赤い網掛け)です。ステップ3の「カット一覧」の“カット”(同じ映像が続くひとまとまり)とは別のものです。
   - **区切る**: タイムラインをクリックすると青い線が入り、ドラッグで動かせます。初期値はカメラが替わる所(音声1本に対して動画を分けて撮った日を想定)で、「↺ カメラが替わる所に戻す」でいつでも戻せます
   - **区切りを消す**: 選んでいる線の上に出る「×」、「🗑 この区切りを消す」、一覧の「🗑 消す」、Delete キーのどれでも消せます
   - **削る**: タイムラインを左右にドラッグした範囲が赤い網掛けになります。表の「🗑 このカットを削る」やタイムラインのダブルクリックで、1つまるごと削ることもできます
   - **削る範囲を直す**: 赤い範囲の**端のつまみをドラッグ**すると、削る所を伸ばしたり縮めたりできます(どのモードでも掴めます)。始め・終わりは ±0.1/±1秒でも微調整できます。伸ばして隣の範囲と重なると1つにまとまります
   - **赤い網掛けを取り消す**: 選んでいる範囲の上に出る「×」、「🗑 この赤い範囲を消す」、一覧の「🗑 消す」のどれでも取り消せます(動画は消えません。網掛けをやり直すためのものです)
   - **画面の見方**: 上がプレビュー、そのすぐ下がタイムライン(編集ソフトと同じ並び)です。タイムラインのすぐ下に、**いま選んでいるもの(区切り or 削る範囲)の調整欄**だけが出ます。区切り・削る範囲の全体一覧は、下の「区切りと削る範囲の一覧」を開くと見られます
   - **表示を動かす**: 拡大したあとは、タイムラインを**左右にドラッグ**すると見る場所が動きます(「見る」「区切る」のとき)。上の見取り図をドラッグしても動かせます。ホイールで拡大・縮小
   - 先に削ってから、残った所を区切ります。削る範囲の中に入った区切りは数えません(灰色で表示)
   - **プレビューは軽い控え(360p)を使います**(「なめらか優先」)。つまみ送りが速くなります。元の画質で見たいときは、チェックを外してください
   - 音声も削った所を飛ばしてつなぎ直します。プレビューの「削る所は飛ばして再生」で仕上がりのまま確認できます
   - **操作はすべて Ctrl+Z で元に戻せます**(画面の「↶ 元に戻す / ↷ やり直す」も同じ)。線をドラッグで動かしたあと、別の操作をしてからでも戻せます
   - 音の波形と、映像のある所/ない所の帯を表示。「◀ 空白 / 空白 ▶」で映像のない所へ移動
   - 「元 13分56秒 → 書き出し 11分51秒(2分5秒を削除)」のように、書き出し後の長さが出ます
   - キーボード: Space 再生、←→ コマ送り、Shift+←→ 1秒、S 区切る、D このカットを削る、Delete 選んでいるもの(区切り/削る範囲)を消す、+/- 拡大・縮小、Ctrl+Z 元に戻す
5. **書き出し** — 映像は 720p/30fps に揃えて作り直し、ラジオ音声をそのまま結合します(コマ数は通しの時刻から決めるので、長い話でも映像と音声がずれません)。
   **画質**は「標準・高画質(既定)・最高画質」から選べます(順に crf 20/fast、crf 16/medium、crf 14/slow)。高画質は標準より時間が約1.7倍・大きさが約2倍で、1時間の話なら 1.9 Mbps → 4.1 Mbps 相当になります。YouTube に上げるなら高画質以上がおすすめです。
   そのほか、要確認の残り・動画の長さ超過・見つからないファイル・空き容量を事前に確認。同名ファイルがあれば別名にし、上書きしません。

## スマホから使う(同じ Wi-Fi)

ふだんは、この PC からしか開けません。スマホを使うときだけ、次のように開きます。

1. PC の画面の右上「📱 スマホ」を押す
2. 出てきた **QR をスマホのカメラで読み取る**。それだけでつながります(合言葉の入力もいりません)
   - QR が読めないときは、表示されたアドレス(例 http://192.168.1.5:8765/)を開いて **6桁の合言葉** を入れます
   - 合言葉は 10 分で切れます。つないだあとのスマホは、そのまま使えます
3. 使い終わったら「つながるのをやめる」を押す(PC を閉じても閉じます)

できること:
- **PC とスマホは同じ状態になります**。片方で変えると、もう片方に数秒で反映されます
  (どちらかに預けていない変更があるときは、上に「取り込む」ボタンが出ます。押すまで置き換わりません)
- スマホの中の動画・音声を「📤 ファイルを送る」で PC に送り、そのまま素材にできます(保存先は `data/uploads/日付`)。3GB くらいの動画で 5〜15 分が目安です
- 照合の開始、進み具合の確認、カット、書き出しの開始まで、PC と同じことができます
- タイムラインは指で操作できます(なぞって移動、2本指でつまんで拡大・縮小)
- プレビューの下に再生バー(いまの位置 / 全体の長さ)が出ます。つまんで好きな場所へ移動できます
- スマホでは、元の大きな動画ではなく**軽量版**を送って再生します(初回だけ変換に時間がかかります)
- 画面が狭いときは、**下のタブ**でステップを移動します。上の「⋯」に保存・開く・新規などをまとめています
- **カット画面はスマホ専用の並び**になります(上からプレビュー → 再生バー → タイムライン → 道具立て)。
  スマホの編集アプリと同じように 1 画面で操作でき、一覧は「☰ 一覧」で下から開きます
- **確認・調整もスマホ用**に並べ替わります(プレビューのすぐ下に「カット◀▶ / OK / 静止画 / 詳しく / ☰一覧」)。
  タイムラインを触っても一覧へ飛ばされません

注意:
- 初めて開くとき、Windows が「このアプリのネットワークアクセスを許可しますか」と聞くことがあります。**プライベートネットワーク**にチェックして許可してください
- 合言葉を知っている人なら、同じ Wi-Fi にいる誰でもつなげます。自宅や事務所など信頼できる Wi-Fi で使ってください(公衆 Wi-Fi では開かないでください)
- 送ったファイルは自動では消えません。いらなくなったら `data/uploads` を削除してください

編集内容は自動でバックアップされ、次回起動時に続きから再開できます。プロジェクトは「保存」でJSONに保存します(0.1と同じ形式)。

## 実装済みと未実装

実装済み: 複数音声・動画の全組合せ照合、前後の一致の連続性によるカメラ区間の判定(低スコア対策)、カメラファイル端での精密な切り替え、ラジオ停止によるずれ変化の検出、ドリフト補正、カメラ優先順位(動画リストの上が優先)、カット単位の確認・調整、抜き取り確認、8秒単位の候補提示、同期プレビュー、波形比較、微調整、近傍再照合、区間の分割・結合、承認、静止画補完、話の区切りと不要部分の削除(カット画面)、元に戻す/やり直し、自動バックアップと再開、照合・書き出しの進捗表示と中止、手動調整した区間(locked)を保持する再照合、話別出力(同じ動画が続く区間はまとめて1回で変換)、書き出し前チェック。

未実装: 話の結合・分割(複数の音声ファイルを1話にする等)、素材の再リンク、照合の高速化(長時間素材では遅い)、exe配布。

## 制約・安全性

- ローカル処理。アプリから音声・動画を外部送信しません。元素材は変更しません。
- 入力パスは絶対パスで保存されます。元素材は同じ場所に保持してください。
- iPhoneのHEVC動画は、ブラウザが対応していればそのまま再生します。再生できない形式(MTS等)は確認画面を開いたときに軽量版(360p)を `data\proxy` に作ります。不要になったら削除して構いません。
- 同期プレビューはブラウザ再生のため数十ミリ秒程度の揺れがあります。最終確認は書き出したMP4で行ってください。
- 一致スコア(正規化波形相関)は反響・別マイク・BGMで低く出ます(実素材で0.1〜0.5程度)。判定は前後のずれの連続性で行うため、低くてもカメラ映像を使います。どのカメラとも連続した一致が見つからない話は、全区間が静止画・要確認になります。
- 全素材の解析音声をメモリに保持し、全区間を総当たり照合します。2時間の音声×2時間の動画で約15分(i7-14700F実測からの概算)。
- 同じカメラの中でラジオ側に編集(カット・並べ替え)があると、ずれの変化として検出しますが、短い編集は見落とす可能性があります。
- 映像は1280×720/30fpsに再エンコードします。動画の最後で音声が映像より0.25秒以内長い場合は最後のコマを伸ばします。無劣化出力ではありません。音声はAAC変換します。音量正規化はしません。

## 開発・引継ぎ

`core.py`: 照合、JSON永続化、FFmpeg出力、進捗・中止。
`server.py`: 操作画面用のローカルWebサーバー(ファイル選択ダイアログ、メディア配信、処理ジョブ)。
`web/`: 操作画面(HTML/CSS/JavaScript、外部ライブラリなし)。
`app.py`: 0.1の旧Tkinter画面(参考用。`.venv\Scripts\python.exe app.py` で起動可能)。
`test_core.py`: 合成データによるユニット・メディア統合テスト。
`DESIGN.md`: 合意した完成仕様、現版との差分、次の実装順。
`data/`: 自動バックアップ、プレビュー用軽量版、ログ(`server.log`)。

テスト: `.venv\Scripts\python.exe -m unittest -v test_core.py`
