# 制作ハブ

Radio Sync(ラジオ音声とカメラ映像を合わせて話ごとの動画を作る)と、動画クリッパー(テロップ・切り抜き)を1か所から使うための入口です。このPCの中だけで動きます。

## 使い方

1. `start_hub.bat` をダブルクリックすると、Edge の専用ウィンドウでハブが開きます。
2. 各ツールの「起動して開く」でツールを起動します(動いていれば「開く」)。
3. Radio Sync で書き出した動画が「Radio Sync で書き出した動画」に並びます。「テロップ・切り抜きへ送る」を押すと、動画クリッパーが止まっていれば起動し、その動画を選んだ状態の画面が開きます。処理内容を選んで「処理を開始」を押してください。
4. 動画クリッパーの完成品は「動画クリッパーの完成品」から開けます。

ウィンドウを閉じると、約3分後にハブも自動で終了します(ツール本体は終了しません)。

## 仕組み

- `hub.py` … ハブ本体(Python標準ライブラリのみ)。127.0.0.1 だけで待ち受け、起動ごとの合言葉が必要です。
- `hub.html` … ハブの画面。
- `hub_config.json` … ツールの場所。初回はハブのフォルダの親(ダウンロード)から自動で探します。画面の「ツールの場所」で変更できます。
- Radio Sync は書き出した動画を `radio_sync\data\exports.json` に記録し、ハブはそれを一覧にします。
- 動画クリッパー(v7)への受け渡しは `pythonw server.py --open "動画のパス"` で行います。動画クリッパーが動いていればそのウィンドウに、止まっていれば起動して動画を渡します。受け取った動画は元の場所から読むだけで、コピーも変更もしません。

## 必要なもの

- Python 3(Radio Sync・動画クリッパーと同じPython。ハブは追加のライブラリ不要)
- Radio Sync と 動画クリッパー v7(どちらも `setup_windows.bat` 実行済み)
