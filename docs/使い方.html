ラジオ制作ツール 手引き

入れ方・更新のしかたと、画面ごとの使い方をまとめています。

「はじめる」を押すだけになりました Python や FFmpeg を自分で入れる必要はありません。フォルダを手で上書きする更新作業も要りません。 はじめる.bat をダブルクリックすれば、足りないものを揃えて、新しい版があれば更新して、そのまま起動します。
はじめて使うとき

入れかた

1
一式をダウンロードする

受け取ったリンク（GitHub のページ）を開き、緑の Code ボタン → Download ZIP を押します。 ZIP を直接渡された場合は、それをそのまま使ってください。

2
展開して、置いておきたい場所に移す

ZIP を右クリック →「すべて展開」。出てきたフォルダを、ドキュメントなど分かりやすい場所に置きます。 あとで動かしても問題ありません。

3
はじめる.bat をダブルクリックする

黒い窓が開いて、必要なものを順に取ってきます。初回は3分ほどかかります。終わるとブラウザが開いて、すぐ使えます。

4
次からはデスクトップの「ラジオ制作ツール」から

初回に作られるアイコンをダブルクリックすれば、同じように起動します。

PC の設定は変わりません Python も FFmpeg も、一式フォルダの中の runtime に入ります。すでに自分で入れている人は、そちらがそのまま使われます。 インターネットが要るのは、初回に取ってくるときだけです。
2回目から

更新のしかた

やることは はじめる.bat を押すだけです。新しい版があるときだけ聞かれます。

  • 作業中のものは消えません。プロジェクト・書き出した動画・設定（data / results）は入れ替えの対象外です。
  • 失敗しても元に戻ります。途中で通信が切れたときは、入れ替えをやめて元の状態に戻してから終わります。そのまま今までどおり使えます。
  • あとにもできます。「N」を選べば起動だけします。次に開いたときに、また聞かれます。
使い方 1

Radio Sync

ラジオ音声とカメラ映像を突き合わせて、本編の動画を作ります。画面は上のタブで 1 → 5 と進みます。

1 素材を選ぶ

  • ラジオ音声を追加します。1ファイルが1話になり、上から「第1話、第2話…」の順になります。
  • カメラ動画を追加します。台数・本数に制限はありません。
  • フォルダごと入れるときは「フォルダを選ぶ」。映像のないファイルを音声、あるファイルを動画に自動で振り分けます。
  • 「映像がない所に表示する画像」を決めておくと、カメラが回っていない区間がその画像になります。

2 自動照合

  • 「照合を始める」を押すと、カメラの音を手がかりに、どの時間にどのカメラを使うかを自動で決めます。
  • 所要時間の目安と、進み具合・残り時間が出ます。途中で止めることもできます。
  • 終わると「要確認」の件数が出ます。件数が多くても、次の画面でまとめて確認できます。

3 確認・調整

  • 上のプレビューで再生し、映像と音が合っているかを確かめます。
  • ずれているときは、下の波形を左右にドラッグして山をそろえます。スライダーや ±コマのボタンでも直せます。
  • 合っていれば OK。カメラが写っていない所は「静止画にする」で画像に差し替えられます。
  • 右のカット一覧には、同じ映像が続くまとまりが並びます。「要確認」だけを絞り込めます。

4 カット

  • 区切る…タイムラインを押すと青い線が入り、そこでファイルが分かれます。線はドラッグで動かせます。
  • 削る…タイムラインをなぞった範囲が赤くなり、書き出しから外れます。端のつまみで伸ばし縮みできます。
  • 見る…押した場所を再生します。左右にドラッグすると表示位置が動きます。
  • 下に「元 13分56秒 → 書き出し 11分51秒」のように、仕上がりの長さが出ます。
  • 操作はすべて Ctrl+Z で元に戻せます。

5 書き出し

  • 画質を「標準／高画質／最高画質」から選びます。既定は高画質です。
  • 書き出し先のフォルダを選ぶと、作られるファイル名と長さの一覧が出ます。
  • 同じ名前のファイルがあるときは別名にして、上書きを防ぎます。
  • 要確認が残っている・空き容量が足りないといった注意は、始める前に表示されます。
使い方 2

動画クリッパー

出来上がった動画にテロップを入れ、盛り上がった所を切り抜きます。

1 動画を選ぶ

  • Radio Sync で書き出した動画を選びます。制作ハブの「テロップ・切り抜きへ送る」を使うと自動で入ります。
  • 下の「最近の処理」から、前に作ったものを開き直せます。

2 処理の設定

  • テロップ…フォント・大きさ・位置・ふちどりを決めます。見本がその場で変わります。
  • 切り抜き…本数と1本あたりの長さを決めます。
  • 話の見出し…いま何の話をしているかを左上に出すかどうかを選べます。

3 処理

  • 書き起こし → テロップの焼き込み → 切り抜きの作成、を続けて行います。
  • 進み具合と、いま何をしているかが出ます。長い動画では時間がかかるので、そのまま置いておけます。

4 確認・修正

  • 出来上がった動画と切り抜きを、その場で再生して確かめられます。
  • テロップの文言をその場で直せます。分けたり、足したりもできます。
  • 直したら「テロップを焼き直す」で作り直します。
使い方 3

スマホから使う

同じ Wi-Fi につないだスマホから、PC と同じ画面を操作できます。ふだんは閉じていて、押したときだけ開きます。

1
スマホを、PC と同じ Wi-Fi につなぐ
2
PC の画面の右上「スマホ」を押す

QR と6桁の合言葉が出ます。

3
QR を読み取る

それだけでつながり、PC と同じ状態で開きます。読めないときは、表示されたアドレスを開いて合言葉を入れてください（10分で切れます）。

4
使い終わったら「つながるのをやめる」を押す

PC の画面を閉じても、つながりは閉じます。

信頼できる Wi-Fi でだけ使ってください 合言葉を知っていれば、同じ Wi-Fi にいる人はつなげます。自宅や事務所では問題ありませんが、公衆 Wi-Fi では開かないでください。
初めて開くとき、Windows が「このアプリのネットワークアクセスを許可しますか」と聞くことがあります。プライベートネットワークにチェックして許可してください。
最後に

困ったとき

「はじめる」を押しても、必要なものを取ってこられない
インターネットにつながっているか確かめて、もう一度押してください。会社のネットワークなど、通信が制限されている場所では取ってこられないことがあります。取ってくるのは初回だけです。
更新の途中で失敗した
元の状態に戻してから終わるので、そのまま今までどおり使えます。しばらく経ってから、もう一度「はじめる」を押してください。
画面の上に「ツールが新しくなっています」と出る
ツールを開いたまま更新すると出ます。いったん閉じて、もう一度「はじめる」から開き直してください。
前に書き出した動画の映像と音がずれている
更新前の不具合です。更新したあと、同じプロジェクトを開いて「5 書き出し」からもう一度書き出してください。
スマホでプレビューがすぐ出ない
スマホには軽い控えを作ってから送ります。初回だけ変換に数分かかり、その間は「軽量版を作成中…」と出ます。一度作れば、次からすぐ出ます。
書き出しに時間がかかる
画質の設定を見直してください。「標準」がいちばん速く、「最高画質」は約3倍かかります。書き出し中は PC が重くなりますが、終われば戻ります。
全部消してやり直したい
一式フォルダごと削除すれば、きれいに消えます。PC の他の場所には何も入れていません（デスクトップのアイコンだけ手で消してください）。
